# Neolink Home Assistant add-on

Local add-on wrapping the `ghcr.io/mutuallyassureddeployment/neolink` image.

Install: copy this folder to `/addons/neolink` on HAOS (Samba share `addons`), then
Settings → Add-ons → Add-on Store → ⋮ → Check for updates → **Local add-ons → Neolink**.
See DOCS.md for options and the Frigate config.
